# Archive preparation changes

The original recovered notebooks were not modified. The copies in `notebooks/` were prepared as follows; `SANITIZATION.json` records each changed or removed original cell index and the original file hashes.

- Removed Otter initialization, public-test calls, export calls, top-level Otter test metadata, cell grading/locking metadata, and execution timestamps. These are course-platform integration, not the classification algorithms.
- Removed optional `%pip install iwut`, `%load_ext iwut`, and `%wut` diagnostic setup. Replaced `%matplotlib inline` with a comment so every retained code cell can be parsed as plain Python.
- Removed empty cells, unused collaborator placeholders, decorative completion media, and obsolete feedback/submission-export instructions. No collaborator name was present in the placeholders.
- Cleared saved raw training-row/email previews from B1 original cells 11 and 15, and B2 original cells 12, 49, 51, 53, and 65. These previews included public-corpus email addresses and unrelated message bodies. The analysis/display code itself remains, so obtaining and rerunning the dataset can recreate such previews.
- Retained aggregate metric outputs, feature-analysis plots, and the ROC plot. Replaced the original environment prefix in the saved convergence-warning path with `[original notebook environment]/`, preserving the warning's meaning.
- Changed B2's CSV export naming and text from a Gradescope submission workflow to a local `predictions_*.csv` download. The `Id`/`Class` schema and predictions are unchanged; no remote submission action is present.
- Replaced local links to missing instructional diagrams with verified official upstream URLs. Preserved course prompts, attribution, and student written answers.
- Added a readable B2 helper by copying the original B1 `words_in_texts` function, plus documentation and offline checks. No feature/model implementation was rewritten.

The notebook source scan found no student-ID field, user-directory path, or credential assignment requiring removal. All eight email-address literals found in saved outputs were in the removed raw-email previews; no address literal remains in the sanitized notebooks. This is a targeted preparation check, not a guarantee about any future outputs generated by rerunning the corpus.

The model/feature cells selected in the preparation manifest were compared to their recovered sources and remained byte-for-byte identical. Original written reflections are preserved even where they describe processing absent from the code; the README and validation record distinguish the implemented behavior.
